# ag 完整使用指南

> 适用版本：ag 1.0.0
> 环境：macOS / Linux · zsh（补全需要）· Python 3.11+
> 定位：把所有 AI coding agent 收进一个命令里，随意切换、自由扩展
> 前置阅读：[README](../README.md)（安装、它解决什么问题）

---

## 一、它解决什么问题

手上装了十几个 AI coding agent，各自的启动方式都不一样：

- 有的命令名就是启动指令（`codex`、`gemini`、`goose`）
- 有的靠 `.zshrc` 里的别名（`cc`→`claude`、`oc`→`opencode`、`d`→`dsh-tui`）
- OpenClaw 有 8 个角色会话，每个都得敲一长串 `openclaw tui --session agent:xxx:main`
- Hermes 有 3 套 profile，Pi 系有 `pi` / `omp` 两种

结果是：**记不住、找不着、加减一个就要动 `.zshrc`。**

`ag` 把这些问题收在一处：

| 原来的麻烦 | 现在的做法 |
|---|---|
| 十几套启动方式要分别记 | `ag` 一个命令，选择器里挑 |
| OpenClaw 会话串太长 | `ag ot-design` 就行 |
| 加新 agent 要改 `.zshrc` 再重开 shell | `ag add`，存完立刻生效 |
| 装了但忘了叫什么 | `ag scan` 扫出来 |
| 不知道哪个还能跑 | `ag doctor` 体检 |

> **原有的 shell 别名一个都不用删**，`cc` `oc` `d` 照旧能用。
> `ag` 是加在上面的一层统一入口，不是替换。

## 二、30 秒上手

```bash
ag            # 打开全屏选择器：打字即筛选，↑↓ 移动，回车启动，Esc 退出
ag cc         # 直接启动 Claude Code
ag ot-ceo     # 直接进 OpenClaw 的 ceo 会话
ag 设计        # 中文搜索 → 直接筛到 ot-design
ag cc --resume    # 后面的参数原样透传给 agent 自己
```

按 **Ctrl-G** 可以在任意命令行提示符下直接召唤选择器，不用先敲 `ag`。

`ag <Tab>` 出全部短名补全。

## 三、命令全表

### 启动

| 命令 | 作用 |
|---|---|
| `ag` | 打开模糊选择器 |
| `ag <id>` | 精确启动，例 `ag cc` / `ag ot-product` |
| `ag <id> [参数...]` | 参数透传，例 `ag cc --resume` / `ag gemini -m pro` |
| `ag <关键词>` | 没精确匹配时，打开预填关键词的选择器 |

### 管理

| 命令 | 作用 |
|---|---|
| `ag ls` | 列出全部，`●` 能跑 / `○` 缺失，并提示怎么装 |
| `ag ls --all` | 连 `hidden = true` 的一起列 |
| `ag ls --json` | 输出 JSON，方便喂给别的脚本 |
| `ag add` | 向导式添加新 agent |
| `ag rm <id>` | 删除（只删那一块，注释保留，删前自动备份） |
| `ag edit` | 用 `$EDITOR` 打开注册表手改 |
| `ag scan` | 扫描 `PATH`，揪出装了但没登记的 agent |
| `ag doctor` | 体检：每条都解析一遍真实路径 |
| `ag install <id>` | 按登记的 `install` 命令安装 |
| `ag install --missing` | 一键补装所有缺失的 |
| `ag which <id>` | 看实际会执行什么命令、在哪个路径 |
| `ag path` | 打印注册表路径 |
| `ag help` | 帮助 |

## 四、选择器怎么操作

```
  ag Agent Gateway  29/29 · 选一个 agent · 输入即筛选
  ❯ █
  ────────────────────────────────────────────────────────
  ● ot-ceo        OpenClaw · ceo 内容策划          内容策划
  ● ot-finance    OpenClaw · finance 社群运营       社群运营
  ● oc            OpenCode                         开源终端编码 agent
  ────────────────────────────────────────────────────────
  openclaw tui --session agent:ceo:main  tags: openclaw,team
  ↑↓/Ctrl-P,N 移动 · Enter 启动 · Esc 退出 · Ctrl-U 清空
```

| 按键 | 作用 |
|---|---|
| 直接打字 | 追加到筛选词（支持中文） |
| `↑` `↓` / `Ctrl-P` `Ctrl-N` | 上下移动 |
| `PgUp` `PgDn` / `Home` `End` | 翻页 / 跳首尾 |
| `Backspace` | 删一个字符 |
| `Ctrl-U` | 清空筛选词 |
| `Enter` | 启动选中项 |
| `Esc` / `Ctrl-C` | 退出，什么都不启动 |

**能搜什么**：短名、显示名、说明、标签、别名，中英文都行。

```
ag 设计        →  ot-design
ag 文案写手     →  ot-dev
ag wrapper     →  omc / omx
ag deepseek    →  d
```

排序规则：精确短名 > 短名前缀 > 短名含 > 显示名前缀 > 别名前缀 > 主字段含 > 只在说明/标签里命中（沉底）。所以打 `ce` 时 `ot-ceo` 会排在 `goose`（因为 `opensource` 标签里含 `ce`）前面。

行首的 `●` / `○`：**绿点 = 可执行文件找得到，红圈 = 没装**。选中红圈那行时，底部会显示安装命令。

## 六、加自己的 agent

### 办法 A：向导（最省事）

```bash
ag add
```

一路回车问下来（短名、显示名、可执行文件、参数、说明、标签、别名、安装命令、启动目录），加完**立刻可用**，不用重开 shell。

### 办法 B：一行命令

```bash
ag add --id myagent --cmd myagent --name "我的 Agent" \
        --desc "干什么的" --tags "自研,内部" --alias ma \
        --install "npm i -g myagent"
```

### 办法 C：直接改注册表（最灵活）

```bash
ag edit          # 或 vim ~/.agents/registry.toml
```

在文件末尾追加一块，**保存即生效**：

```toml
[[agent]]
id = "myagent"                # 必填，唯一短名，就是 `ag myagent` 敲的那个
name = "我的 Agent"            # 显示名
cmd = "myagent"               # 必填，可执行文件名或绝对路径
args = ["--flag", "value"]    # 固定参数，每次启动都带
desc = "一句话说明"            # 选择器里显示
tags = ["自研", "内部"]        # 标签，可被搜索
alias = ["ma", "mine"]        # 额外别名
env = { API_KEY = "sk-xxx" }  # 启动时注入的环境变量
cwd = "~/work"                # 启动目录，支持 ~
install = "npm i -g myagent"  # 安装命令，供 `ag install` 用
hidden = false                # true 则不进选择器，但仍可 `ag <id>` 启动
```

### 字段速查

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | ✅ | 唯一短名，全局不能重 |
| `cmd` | ✅ | 可执行文件名（走 `PATH`）或绝对路径 |
| `name` | | 显示名，缺省用 `id` |
| `args` | | 固定参数数组，写在 `cmd` 之后 |
| `desc` | | 一句话说明 |
| `tags` | | 标签数组，参与搜索但排序沉底 |
| `alias` | | 额外别名数组，`ag <alias>` 等价于 `ag <id>` |
| `env` | | 内联表，启动时合并进环境变量 |
| `cwd` | | 启动前 `chdir` 到这儿 |
| `install` | | 安装命令，`ag install <id>` 会执行它 |
| `hidden` | | `true` 则不出现在选择器列表 |

### 删除

```bash
ag rm myagent
```

按 `[[agent]]` 块整块删除，**文件里的注释和分节小标题都会保留**。改动前自动备份到 `~/.agents/backups/`（只留最近 20 份）。

## 七、日常维护与排障

### 体检

```bash
ag doctor
```

逐条解析真实路径，输出类似：

```
● d                /Users/you/.nvm/versions/node/v24.0.0/bin/dsh-tui
● cc               /Users/you/.local/bin/claude
○ foo              未安装  npm i -g foo

29/29 可用。
```

### 发现漏网的

```bash
ag scan
```

扫描 `PATH`，比对一份 40 多个常见 agent 名字的清单，列出**装了但没登记**的。当前扫出 7 个：

```
hermes-agent  cursor-agent  qwen  clawdhub  clawhub  agent-browser  cua-driver
```

想收进来就 `ag add` 一下。

### 看某条到底执行什么

```bash
ag which cc
```

```
  id    : cc
  name  : Claude Code
  命令  : claude
  路径  : /Users/you/.local/bin/claude
```

### 缺失的一键补装

```bash
ag install --missing
```

会按各条登记的 `install` 命令逐个执行（**注意**：里面有的是 `curl ... | sh`，属直接执行远端脚本，跑之前自己心里有数）。

### 用另一份注册表

```bash
export AG_REGISTRY=~/proj/agents.toml
ag ls
```

`ag` 本体、补全、备份都会跟着走。适合给某个项目单独配一套入口。

## 八、和 provider 切换器的分工

很多 agent 生态里还有一个「切换供应商 / 模型 / API Key」的需求，
通常由 cc-switch 这类工具负责。它和 `ag` **不冲突，建议并用**：

|               | 管什么                                | 例子                     |
| ------------- | ---------------------------------- | ---------------------- |
| **cc-switch** 等 provider 切换器 | 同一个 agent 换 **供应商 / 模型 / API Key** | Claude Code 从官方切到中转站 |
| **ag**        | 换 **哪个 agent**，以及怎么启动它             | 从 Claude Code 换到 Codex |

一句话：**`ag` 负责把进程拉起来，拉起来之后走哪家 API 仍然归 provider 切换器管。**

## 九、文件位置

| 路径 | 作用 |
|---|---|
| `~/.local/bin/ag` | 主程序（Python，只用标准库，无第三方依赖） |
| `~/.agents/registry.toml` | **注册表 —— 平时要改的就是这个** |
| `~/.agents/ag.zsh` | zsh 补全 + `Ctrl-G` 快捷键 |
| `~/.agents/registry.example.toml` | 模板副本，`ag add` 时可参考 |
| `~/.agents/backups/` | 注册表自动备份（改注册表前自动存，保留最近 20 份） |
| `~/.zshrc.bak-ag-<时间戳>` | 安装脚本改动 `.zshrc` 前的备份 |

想跑回归测试得用仓库里的那份（`tests/`），安装脚本不会把它下到 `~/.agents/`。

`.zshrc` 末尾加了一段（**只加了这一段，别处没动**）：

```zsh
# >>> ag — Agent Gateway >>>
export PATH="$HOME/.local/bin:$PATH"
[[ -r "$HOME/.agents/ag.zsh" ]] && source "$HOME/.agents/ag.zsh"
# <<< ag — Agent Gateway <<<
```

这段是**幂等**的：重复跑安装脚本，检测到已有标记就跳过，不会重复追加。

不想要 `Ctrl-G` 快捷键，在这个块之前加一行：

```zsh
export AG_NO_KEYBIND=1
```

## 十、常见问题

**改了注册表要重启 shell 吗？**
不用。`ag` 每次运行都重新读注册表，保存即生效。只有改 `.zshrc` 才需要重开或 `source ~/.zshrc`。

**启动报"找不到可执行文件"？**
那条的 `cmd` 不在 `PATH` 上。两个解决办法：`cmd` 直接写绝对路径，或者把它的 bin 目录加进 `PATH`。先 `ag doctor` 看是哪条断了。

**想同时开好几个 agent 并行干活？**
每个 `ag <id>` 是独立进程，开几个终端窗口各跑各的就行。要多窗格同屏用 tmux：

```bash
tmux new -s work
# 然后 Ctrl-B % 分屏，每个 pane 里 ag <id>
```

**选择器行首是红圈 `○`？**
可执行文件没找到。选中那行，底部会显示安装提示；或直接 `ag install <id>`。

**能登记非 AI agent 的命令吗？**
能，它本质就是个"带参数的启动器"。任何常用命令都能收进来：

```bash
ag add --id k9s --cmd k9s --desc "K8s 面板"
ag add --id gp --cmd git --args "pull --rebase" --desc "拉取变基"
```

**短名和已有命令重名了怎么办？**
`ag` 是独立命令名，不会抢。但注意 `ag ls` 里的 `ls` 是 `ag` 的子命令——如果你登记了一个短名叫 `ls` 的 agent，会**优先走子命令**。换个短名，或在注册表里改名。

**出问题了想回滚？**
注册表备份在 `~/.agents/backups/registry.<时间戳>.toml`，直接覆盖回去：

```bash
cp ~/.agents/backups/registry.20260930-221638.toml ~/.agents/registry.toml
```

## 十一、按场景速选

| 场景 | 推荐入口 |
|---|---|
| 日常主力编码 | `ag cc` |
| 多角色协作（选题→研究→写作→发布） | `ag ot` 及 `ag ot-*` 矩阵 |

| Web 界面操作 | `ag dsh-web` / `ag hwu` |
| 不知道用哪个 | 直接 `ag`，搜关键词 |
